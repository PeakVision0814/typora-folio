# 纸间，让文字慢下来

Folio · 阅读与写作札记

一个安静的写作空间，应该让内容先被看见。纸间以温暖的纸色、克制的苔绿与清晰的文字层次，陪伴每一次阅读、思考和落笔。

English typography matters, too. Good writing leaves room for thought. **清楚的层次**、*轻柔的强调*，以及 ==值得记住的一句话==，共同构成阅读的节奏。

## 01 阅读的秩序

标题像路标，段落像呼吸。让章节之间多一点留白，让正文保持自然的左对齐，中英文混排也能拥有稳定的节奏。

> 阅读不是匆忙地抵达结尾，而是在文字之间，发现自己的问题。
>
> A quiet page makes space for a clear thought.

### 从一页笔记开始

- 用 **重点** 建立层次，用链接连接知识。
  - 中文、English、数字 2026，应自然地排在一起。
- 行内代码如 `reading_width = 800`，保持简洁清楚。

2. 归纳与验证

## 02 细节的分寸

| 元素 | 亮色 · Folio | 暗色 · Folio Night |
| :--- | :--- | :--- |
| 底色 | 暖白纸色 | 暖炭黑 |
| 强调 | 苔绿 | 鼠尾草绿 |
| 正文 | 宋体与 STIX | 同一套排版 |

```python
# 留白也是排版的一部分
def reading_time(words: int, speed: int = 300) -> float:
    return words / speed

title = "纸间 · Folio"
minutes = reading_time(1200)
print(f"{title}: {minutes:.1f} min")
```

### 公式与注释

行内公式 $E = mc^2$ 应与文字自然衔接。独立公式保持清晰的数学字形：

$$
\int_0^1 x^2\,\mathrm{d}x = \frac{1}{3}
$$
